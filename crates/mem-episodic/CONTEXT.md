# mem-episodic

**Purpose:** per-project agent session (episodic) memory: session summaries, timelines, consolidation.

**Ubiquitous language:** terms pinned by the W4.1 (episodic schema & scoping), W4.2 (timeline queries & recall) and W4.3 (episodic consolidation & compaction) tracer waves; see `docs/adr/0005-episodic-storage-model.md` for the storage-model decisions and `docs/adr/0006-episodic-consolidation.md` for the consolidation decisions.

| Term | Meaning |
|---|---|
| **AgentSession** | One persisted episodic record bound to the non-optional scope triple `(project_id, session_id, agent_id)`; carries `parent_session_id`, `summary`, `metadata`, `embedding`, `created_at`, `updated_at`, `deleted_at`, `orphaned`. Row id is minted SQL-side as a UUIDv7. |
| **SessionMetadata** | Structured payload serialized as the camelCase `metadata` TEXT column: `timestamp`, `agent_name`, `git_branch`, `git_commit`, `files_touched`, `completed_work`, `decisions`, `open_threads`, plus `extra` (unknown keys preserved verbatim). |
| **NewAgentSession** | Validated input shape before persistence; `into_session(now)` fills the `agent_name` default (empty → `agent_id`), stamps `created_at == updated_at == now`, and leaves `id`/`embedding` empty and `deleted_at`/`orphaned` at their live defaults. |
| **WorkKind** | `feature` / `bugFix` / `command` / `other`. |
| **WorkItem** | `{ kind, description }` entry in `completed_work`. |
| **Decision** | `{ description }` entry in `decisions`. |
| **EpisodicStore** | Owner of the dedicated `episodic.db`; migration set v1 + v2 (`episodic` label, per-version identity in each `SchemaMigration.description`); insert/get/detail/list/delete/soft-delete/semantic-search + embedding read-back + the project-scoped timelines and parent/child linking. |
| **Scope triple** | `(project_id, session_id, agent_id)` — the `UNIQUE` key and every read path's project filter; no cross-project bleed. |
| **Conflict** | Dedicated error variant for a duplicate scope triple (`EpisodicError::Conflict`); the driver's unique-violation text never leaks. |
| **NotFound** | Dedicated error variant for a missing/invisible addressed row (`EpisodicError::NotFound { entity }`, `entity` = `child_session` / `parent_session`); a wrong-project or soft-deleted endpoint never leaks existence. |
| **Embedded document** | The locked template `"Session {session_id} by {agent_id} on {branch}: {summary}. Completed: {completed_work}. Decisions: {decisions}."` (branch absent → `unknown branch`), prefixed via `apply_task_prefix(..., EmbedTask::Document, ...)`; `summary` is also stored verbatim. |
| **Timeline** | The project-scoped ordered view over episodic sessions; three modes: **chronological** (`created_at DESC, id DESC`), **filtered** (the same statement with AND-only optional predicates), **semantic** (query embedding + exact `vector_distance_cos` ranking — no vector index in this tier). |
| **TimelineFilter** | The AND-only optional predicate set (`since`, `until`, `last_n_sessions`, `touched_files`, `agent_id`, `session_id`); values are validated before use and never coerced. `touched_files` is an ANY-match evaluated in Rust, so there is no join table. |
| **SessionSummary** | The listing shape (id/scope/agent/summary/parent link/orphan flag/files/created/updated, optional `similarity`); the full `AgentSession` is returned only on demand via `session_detail`. |
| **Soft delete** | `deleted_at` (unix millis, NULL = live). A soft-deleted row is invisible to every read path (`get_session`, `session_detail`, `list_sessions`, `search_sessions`, both timelines, `count_sessions(Some)`, `link_parent`/`unlink_parent` endpoints) except two raw diagnostic seams (`count_sessions(None)`, `embedding_for`); the row and its embedding survive. |
| **Orphaned** | `orphaned = 1` marks a record whose parent link was severed by a delete of that parent; it is a persisted write-time flag (set by both delete paths, cleared by `link_parent`/`unlink_parent`), never a computed view. Read paths keep a flagged entry — they never drop it. |
| **`recall_project_sessions`** | The typed tool schema (args + JSON schema + result shape) for the query half of US 1.4; registration is W5.4. |
| **Parent linkage** | `parent_session_id` self-reference with `FOREIGN KEY ... ON DELETE SET NULL` — deleting a parent severs its children's link without cascading. Both endpoints must be visible; `link_parent` rejects self-links, cross-project parents and cycles, and `unlink_parent` is idempotent. |
| **Milestone** | The W4.3 surviving record of one consolidated `(project_id, agent_id)` window: `id` (UUIDv7, minted by the store's id path), `project_id`, `agent_id`, `summary`, `contributors`, `source_count`, `window_start`, `window_end`, `created_at` — plus a write-only `embedding` (`#[serde(skip)]`, never read back). One row per `(project_id, agent_id)` per consolidation. |
| **Contributor** | One source session behind a milestone: `session_row_id`, `session_id`, `parent_session_id`, `agent_id`, `agent_name`, `created_at` and the **retained `summary`** — the source session's own summary text, privacy-stripped and retained VERBATIM so the raw per-session text stays recoverable after the source row is hard-deleted. A source summary that strips to empty is still listed, with an empty retained text. |
| **Contributors JSON** | The encoded `Vec<Contributor>` bound into the milestone's `contributors` TEXT column. Its bound is `max_contributors_bytes(row_count) = MAX_TRANSCRIPT_BYTES + 1_536 × row_count`, measured on the ASSEMBLED JSON (JSON escaping expands the retained text up to 6×, so the raw text is NOT bounded by the transcript cap). Over-bound ⇒ per-agent skip (`ContributorsTooLarge`); never a truncation, never a dropped contributor. |
| **Consolidation** | The W4.3 age-based job: fold the live sessions older than `episodic.consolidationAgeDays` into one milestone per `(project_id, agent_id)`, promote their decisions, and remove the merged source rows in ONE atomic write batch. Per agent the order is (a) claim → (b) transcript + prefix → (c) summarize + validate → (d) embeddings + dimension checks + the contributors bound → (e) existence-checked promotions → (f) ONE episodic write batch. Phases (a)–(d) perform zero writes when they fail. |
| **Promotion** | Moving a session's DECISION into the permanent project memory tier under the CALLER-supplied `PromotionScope` (`container_tag` + `scope_hash`) — never a scope derived from the episodic `project_id`. The promoted row's `memory_type` is the free-form string `"decision"` and its id is `"episodic-decision-"` + the first 32 hex of `sha256(project_id + "\u{1f}" + key)`, so promotion is idempotent across runs. |
| **PermanentMemorySink** | The promotion port: `promote(scope_hash, record) → PromoteOutcome::{Inserted, AlreadyPresent}`. The `AlreadyPresent` path never bumps the shard's vector count, so a re-run never double-counts. |
| **ConsolidationPolicy** | The age window: `new(age_days)` (0 is rejected), `from_episodic(&config::Episodic)`, and `cutoff(now)` (checked arithmetic; sessions created strictly BEFORE the cutoff are eligible). |
| **In-process consolidation gate** | A process-wide, std-only registry keyed by the CANONICAL storage path (`OnceLock` + `Mutex<HashMap<PathBuf, Arc<AtomicBool>>>>` + `compare_exchange`). A second consolidation run in the SAME process is BUSY (zero reads, zero writes); the cross-process case belongs to mem-store's operation lock. |
| **SkipReason** | Why one agent was skipped (the run continues, nothing is written for that agent): `SummarizerError`, `EmptySummary`, `OversizeSummary`, `NoFittingTranscriptRows`, `DimensionMismatch`, `MetadataDecodeError`, `ContributorsTooLarge`. Store, sink and batch errors are NOT skips — they abort the run. |
| **Agent attribution** | Which agent a session belonged to — the identity compaction must preserve. The pinned precedence (upstream `resolveSessionAgent`): the session agent wins outright (trimmed, no message scanned); otherwise ONE newest→oldest scan, where a user message contributes its `agent`, an assistant message is SKIPPED when `summary === true` or `mode == "compaction"` and otherwise contributes `agent ?? mode` (an assistant with neither a non-blank `agent` nor a non-blank `mode` keeps the scan going), and every other role is skipped; otherwise none. |

**W7.1 additions (raw context, cross-tier, erasure):**

> Raw context is never destroyed by consolidation or by any lifecycle stage;
> it is destroyed only by an explicit, owner-initiated purge
> (`purge_session`).

| Term | Meaning |
|---|---|
| **RawContext** | The authoritative per-session bytes, stored in the `episodic_raw_context` TABLE keyed by the logical triple `(project_id, session_id, agent_id)`. There is deliberately NO `agent_sessions.raw_context` column (one representation only). First write wins; it is validated (non-empty after trim, NUL-free, ≤ 256 KiB) and privacy-stripped before persistence. |
| **RawSegment** | A derived, regenerable slice of the raw context (`episodic_segments`), cut at `\n\n`, else the last `\n`, else a UTF-8 char boundary. `concat(raw_content) == raw_context`, offsets are contiguous, and `segment_index` orders reads. |
| **v6 retention schema** | `agent_sessions.agent_role TEXT NOT NULL DEFAULT 'main'`, `episodic_raw_context`, `episodic_segments`, `idx_episodic_segments_session`. NO foreign key, NO cascade, NO trigger — the absence is the invariant. `episodic_migrations()` stays v1..v5; `apply_episodic_schema` applies v6 convergently (pre-flight `PRAGMA table_info`, measured `PragmaOutcome::{InBatch, Fallback, NotAttempted}`). |
| **CrossTierTask** | The phase AFTER the durable consolidation batch: `SessionRef { row_id, session_id, agent_id }`, `CrossTierContext`, `CrossTierReport { promoted, already_present, skipped }`. Distinct from `promotion.rs` (the legacy tier-1 shard sink). `promotion_due` is PURE and keys on `updated_at` versus `promotion.ttlFallbackDays`; a not-due agent is skipped (`PromotionNotDue`) before any write or delete. |
| **SessionScope** | The erasure scope: the visited/trimmed triple. `SessionScope::new` rejects empty/blank/NUL components BEFORE anything is opened. |
| **purge_session** | Erases ONE triple: session rows (live and soft-deleted), raw context, segments, inbox payloads, and every milestone whose decoded contributors name the triple. One write batch; children are ORPHANED, never deleted. Idempotent. |
| **Erasure boundary** | A purge never erases the legacy tier-1 `memories` shard (upstream-golden SQL, no per-session provenance). Every purge success names that surviving tier via `not_erased`. A purge of a contributor also deletes the shared milestone, so the surviving contributor's milestone summary is lost permanently; recovery is an explicit re-capture of the surviving session (its raw context survives). |
| **No tombstone** | Purge writes no tombstone: a later capture of the same triple is a normal write. Consolidation behavior itself is unchanged. |
