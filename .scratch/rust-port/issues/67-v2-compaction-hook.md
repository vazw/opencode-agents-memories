# 67 — V2 first-class compaction hook (pre-compaction ingest)

Status: ready-for-agent — 2026-10-27 (re-verified at `f41b9ef`: the V2 adapter registers only `prompt`/`context`;
the host's own plugins register the compaction hook in four places, and the compaction service describes
consuming its edits. The exact invocation site is the wave's first measurement. Brief under `## Agent Brief`.)

Issue 33 wired the compaction seam for V1: `experimental.session.compacting` for the pre-compaction
ingest, and the `session.compacted` event for the post-compaction restore. Under V2 the **restore** half
is inherited (the adapter forwards every location-matching host event to the V1 `event` hook, and
`LEGACY_EVENT_ALIASES` maps `session.compaction.ended` → `session.compacted`), so the read happens and
`plugin/tests/compaction-v2-inheritance.test.mjs` pins it. The **ingest** half is not wired: the V2 host
exposes compaction under a different extension point, and issue 20's carve froze `plugin/src/v2/**`.

## What, located precisely

- Register `ctx.session.hook("compaction", cb)` in `plugin/src/v2/` so V2 gets a first-class
  pre-compaction ingest. Per `@opencode/plugin@2.0.27` `dist/promise/session.d.ts`:
  `SessionHooks { readonly compaction: SessionCompaction }`, where
  `SessionCompaction extends SessionContext` = `{sessionID, model, system: SystemPart[], messages:
  Message[], options, agent, tools}` with `result?: SessionCompactionResult {summary, native?,
  metadata?, tokens?}`. The callback is a single input and has **no output pair**: it either mutates
  `input.messages` / `input.system` or sets `input.result` to supply the summary and skip the model call.
- The V1 `experimental.session.compacting` contract is an `(input, output)` pair with
  `output.context: string[]`; the two are not interchangeable.

## Three preconditions, all owned here

1. **Confirm host-side V2 dispatch.** Issue 33's P18 confirms the *registrable surface* only, from
   published typings (`@opencode/plugin@2.0.27` and `2.1.4`); no V2 typings are installed locally and
   no host-side caller was observed. Measure that the host invokes a registered `compaction` hook before
   relying on it.
2. **Deliberately unfreeze `plugin/src/v2/**`.** That carve belongs to issue 20. Do not edit the tree
   until the owner records the unfreeze.
3. **Decide the V2 child gate and the send path.** Both currently depend on capabilities
   `createLegacyClient` deliberately omits (`plugin/src/v2/legacy-client.js:117-134` exposes only
   `session.messages` and `tui.showToast`). The V1 handler proceeds on an unknown session (ADR-0017
   DECISION 2) and skips the send when `session.prompt` is absent; the V2 wiring must state its own
   answer, not inherit a silent one.

## Acceptance

- A V2 test proving the registered `compaction` hook receives the session and appends (or sets) the
  session-scoped render — over the real `plugin.setup(ctx)`, with a complete fake `ctx`.
- The child-gate and no-send decisions pinned by tests, not prose.
- ADR-0017's DECISION 5 updated with the measured dispatch result (or the follow-up closed as
  *measurement, not a deliverable* if the host does not dispatch).

## Blocked by / Blocks

- Blocked by: an unfreeze of `plugin/src/v2/**` (issue 20) and a host that dispatches the hook.
- Blocks: nothing in issue 33; the V1 lane is complete without it.

## Agent Brief

> *This was generated by AI during triage.*

**Category:** enhancement

**Summary:** give V2 a first-class pre-compaction ingest by registering the host's `compaction` hook, with
the dispatch measured first and the child-gate/no-send decisions made explicitly rather than inherited.

**Current behaviour (verified at `f41b9ef`):**
- The V2 adapter registers only `prompt` (`plugin/src/v2/adapter.js:36`) and `context` (`:54`); nothing
  registers `compaction`.
- The **restore** half is inherited and pinned: `LEGACY_EVENT_ALIASES` maps
  `session.compaction.ended` → `session.compacted` (`plugin/src/v2/legacy-client.js:25`–`:30`), and
  `plugin/tests/compaction-v2-inheritance.test.mjs` exercises the path.
- `createLegacyClient` exposes only `session.messages` and `tui.showToast`
  (`plugin/src/v2/legacy-client.js:117`–`:134`) — there is **no `session.prompt`**, so the V1 send path cannot
  be inherited as-is.
- ADR-0017 DECISION 5 records all of this and names this issue (`docs/adr/0017-compaction-hook.md:95`–`:106`).

**Host evidence (measured at HEAD):**
- Typings: `SessionHooks { readonly compaction: SessionCompaction }`
  (`packages/plugin/src/promise/session.ts:139`–`:142`), `SessionCompaction extends SessionContext` (`:46`),
  `result?: …` (`:48`).
- The host's **own** plugins register the hook four times: `packages/core/src/plugin/verbosity.ts:39`,
  `optimize.ts:100`, `identity.ts:28`, `warming.ts:135`.
- The compaction service describes consuming hook edits: *"A compaction hook may choose its own kept range"*
  (`packages/core/src/session/compaction.ts:524`) and *"drops a compaction hook's edits to that message"*
  (`:700`).
- **Not yet pinned:** the exact invocation site in the runner. That is the wave's first task, per the issue's
  precondition 1. If a live check shows the host does not dispatch a registered hook, close as *measurement,
  not a deliverable* and record it in ADR-0017 D5.

**Callback shape (not interchangeable with V1):** `ctx.session.hook("compaction", cb)` takes a **single
input**, no output pair. The callback either mutates `input.messages` / `input.system` or sets
`input.result` to supply the summary and skip the model call. The V1 `experimental.session.compacting`
contract is an `(input, output)` pair with `output.context: string[]`.

**The two decisions the wiring must make explicitly:**
1. **Child gate.** The V1 handler proceeds on an unknown session (ADR-0017 DECISION 2). V2 can read the
   session through `session.messages`; decide whether the child gate applies and pin it.
2. **Send path.** V2 has no `session.prompt`. The V1 handler skips the send when it is absent; V2 must either
   do the same with a typed log line, or add the capability deliberately. Do not let it be silent.

**Carve.** Issue 20 is landed and its tracker records **no freeze** of `plugin/src/v2/**` — the carve was that
wave's, not a standing property. This lane owns `plugin/src/v2/plugin.js` and `adapter.js` for the compaction
registration only; `legacy-client.js` changes only if the child gate needs a capability it does not expose.

      receives the session and appends (or sets) the session-scoped render.
